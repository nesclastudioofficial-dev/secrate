# 🚀 Top 20 AI Chat Interfaces - Reverse Engineered UI Components & Vibe-Coding PRDs

An open-source collection of production-ready React + Tailwind CSS components and comprehensive Vibe-Coding PRDs for the world's top 20 AI platforms.

## 🌟 Features
- **20 Full UI Layouts (`.jsx`):** Single-file standalone React components tailored with official brand color palettes and responsive layouts.
- **Vibe-Coding Ready PRDs:** Detailed architectural documents formatted specifically to paste directly into **Cursor, Lovable, Bolt.new, and v0.dev**.

## 🚀 How to Use
1. **For Developers:** Copy any `.jsx` component file directly into your React / Next.js project.
2. **For Non-Coders / Vibe-Coders:** Open the corresponding PRD document, copy the system prompt in Section 5, and paste it into Lovable, Cursor, or v0 to build the full interactive app instantly.
